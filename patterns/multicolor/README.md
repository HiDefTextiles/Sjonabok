# Multi-symbol charts

`issue9-example-1.txt` is the 94 × 120 indexed grid extracted from the first chart image attached to [issue #9](https://github.com/HiDefTextiles/Sjonabok/issues/9). The source image and a rendered preview are included alongside it. The extraction preserves eight recurring symbol classes as integer cell codes (`1`–`8`); `0` marks empty cells. The renderer maps each symbol class to a distinct colour so different source symbols do not collapse into a single filled-cell value.

The issue attachment is a raster screenshot rather than the original EPS. Check the cell transcription and symbol labels against the EPS before treating the matrix as an archival transcription. The second attachment uses a different presentation without detectable chart rules and is not handled by this grid-based path yet.
